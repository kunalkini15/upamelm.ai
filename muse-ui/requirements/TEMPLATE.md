# Requirement title

## User outcome

What should a user immediately understand, feel, or be able to do?

## Current problem

What is weak or confusing in the current rendered experience? Reference
screenshots or states when available.

## Required experience

Describe the important hierarchy, interaction, spatial/3D behavior, and visual
qualities. Leave implementation choices open unless they are genuine product
requirements.

## Important states

List the desktop, compact, interaction, before/after, and error states Muse must
inspect in a real browser.

## Constraints

State factual, accessibility, performance, truthfulness, or compatibility
constraints. Package schemas and registries remain unchanged in refinement.

## Completion evidence

List observable outcomes and screenshots that prove the experience is complete.
